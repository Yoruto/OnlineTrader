OnlineTrader · Windows 便携工作台

双击 OnlineTrader.exe。保留同目录的 _internal 和 OnlineTraderCLI.exe。
账户档案保存在当前 Windows 用户的本地应用数据目录，密码保存在 Windows 凭据库。

系统设置中可以启用「关闭窗口时最小化到系统托盘」。点击窗口关闭键后，双击托盘图标或选「显示窗口」可恢复。托盘菜单的「退出工作台」关闭界面。交易执行器与工作台分开运行，策略启停请使用工作台上的对应按钮。

成交对照.bat 打开本地成交对照。也可以把柜台成交 CSV 拖到脚本上预填。选定原账本、账户和交易日后，可预览并导出 Excel 或 CSV。
核对本机时钟.bat 比对参考时钟并保存「校时报告.txt」。按 S 才会请求 Windows 同步时间。
网络自检.bat 检查天勤相关服务的 DNS、TCP 443 和 HTTPS，并保存「网络自检报告.txt」。
需要工作台随 Windows 登录启动时，可查看「可选_自启动守护」目录。
