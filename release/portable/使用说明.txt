OnlineTrader · Windows 便携工作台

双击 OnlineTrader.exe。保留同目录的 _internal 和 OnlineTraderCLI.exe。
账户档案保存在当前 Windows 用户的本地应用数据目录，密码保存在 Windows 凭据库。

「账号信息」集中管理 SimNow、快期模拟账号及连接设置。「交易参数」集中管理参数模板、交易和定时设置；模板用于保存和应用交易参数组合。主控保留品种列表和策略持仓，顶部保留策略启停。

「添加品种」打开独立表单，输入带月份的合约代码（例如 cu2701 或 铜2701）后自动补全名称。填写偏移和下单手数；半仓比例、滞回点及候选换月合约在「更多设置」。确认和取消固定在窗口底部；确认后新增一行，取消或关闭窗口放弃此次输入。选中一行点击「编辑选中」，或双击该行，可修改这个品种。

编辑参数或应用模板会更新本地草稿。未连接支持运行中保存的策略时，点击「保存参数」可另存为新的 JSON 文件，下次可通过参数中心导入。参数文件不覆盖已有文件。策略支持运行中保存时，「保存参数」把草稿提交给当前执行器。保存成功后，新行情按新参数判断开仓，原持仓继续沿用原保护计划。

点击「启动策略 (F5)」即使用当前账号和交易参数启动，不再弹出二次确认窗口。启动进度和错误显示在主界面，准备期间阻止重复启动。程序自动核对交易日和合约时段，本次运行至对应交易日收盘。已有运行记录需要沿原记录恢复；修改参数预览不会自动改变正在运行的策略。仅打开软件不会连接模拟盘。

「关闭窗口时最小化到系统托盘」默认开启，可在系统设置中关闭。点击窗口关闭键后，双击托盘图标或选「显示窗口」可恢复。托盘菜单的「退出工作台」关闭界面。交易执行器与工作台分开运行，策略启停请使用工作台上的对应按钮。

运行中出现「工作台重连中」或「柜台重连中」时，窗口底部显示已等待时间和倒计时。每轮等待 30 秒后自动重新查询原执行器，也可以点击「立即重连」。原执行器继续管理已有委托和持仓。收到完整同步状态后提示会消失。

首次使用时，K 线图、权益曲线和声音提醒默认开启，字号为 12。修改工作台偏好后，设置保存在程序同目录的 OnlineTrader.ini。移动便携版时，请一起移动这个文件，并确保新目录可写。选择过的参数文件和模板目录仍需在原路径可访问。账户和钉钉凭据由当前 Windows 用户管理。托盘图标也可能在任务栏的隐藏图标菜单中。

成交对照.bat 打开本地成交对照。也可以把柜台成交 CSV 拖到脚本上预填。选定原账本、账户和交易日后，可预览并导出 Excel 或 CSV。
核对本机时钟.bat 比对参考时钟并保存「校时报告.txt」。按 S 才会请求 Windows 同步时间。
网络自检.bat 检查天勤相关服务的 DNS、TCP 443 和 HTTPS，并保存「网络自检报告.txt」。
需要工作台随 Windows 登录启动时，可查看「可选_自启动守护」目录。

随包默认配置（文件放在 EXE 同目录）
OnlineTrader-parameters.json：默认品种和交易参数。每次启动读取。
OnlineTrader-defaults.json：默认模拟账号与钉钉设置。模拟账号在空账户目录首次启动时登记，保留既有账户；钉钉段每次启动读取。
两份文件均可省略。包含密码或机器人密钥的包应仅交给获准使用的人。
