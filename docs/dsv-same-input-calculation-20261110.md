## 为什么这些数值成立

设完整日线基准为B、品种系数为c、当时振幅为R：

1. 基准开仓`O=max(round(B*c),1)`，使用DSV原函数的Python浮点及round。
2. 振幅约束后开仓`max(int(max(min(O,R*0.5),min(O*0.4,O))),1)`。
3. 止盈独立使用`max(round(B*c*0.9),1)`，不从振幅约束后的开仓推导。
4. 止损查固定表，未列品种回退15。

| 棕榈油 | 180.1 | 0.45 | 59 | 81 | 32 | 73 |
| 塑料 | 260.6666666666667 | 0.45 | 111 | 117 | 55 | 106 |
