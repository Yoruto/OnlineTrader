# OnlineTrader 功能实现与待办清单

## Trading Runtime 当前状态

2026-11-19 已实现独立 **Trading Runtime** 源码入口。它复用普通模拟执行链的唯一 Kernel owner、原策略和原每账户 SQLite writer，可在没有 Qt 的情况下完成 SimNow 登录、行情、策略运行、人工开平仓、权限控制、账户查询、跨日历史、停止核对与换机账本导出。Qt 与本机接口进程不是交易 owner，退出不会删除持仓、委托或保护责任。

| --- | --- | --- |

## 状态口径

- **底座已实现**：对应机制已有实现；不代表所有账户、通道和实机故障均通过。
- **已实现，待在线验收**：对应产品代码链已有实现，在线证据仍单列。
- **本地工具已实现**：已有本地编辑、查看或导出入口，权限与输入范围仍受约束。
- **部分实现 / 未实现**：明确剩余内容；不把规划、配置字段或数据库表单独当完成。
- **作者记录 / 独立核验 / SKIP / NOT_RUN**：证据可得性与执行状态分开记录，不从标题或数量推断。
