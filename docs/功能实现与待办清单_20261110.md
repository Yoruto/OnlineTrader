# OnlineTrader 功能实现与待办清单

## Trading Runtime 当前状态

2026-11-21 当前 **Trading Runtime** 默认使用 Standalone 入口和 DSV Target Owner：单一 DSV Strategy + `ExplicitOrderController` + SDK sender，每个 boot 使用进程拥有的临时 Journal，并从柜台同步当前持仓、委托、成交和资金。一台 Windows 电脑最多一个 Runtime，不同电脑可同时使用同一期货账户。Qt 与 runtime-view 是读/控制侧进程，不持有 SDK 或 Journal writer；旧执行账本仅作为只读历史制品，不交接、不阻塞启动。

- **部分实现 / 未实现**：明确剩余内容；不把规划、配置字段或数据库表单独当完成。
