## CSV列映射和解析

| 规范意义 | 源尝试的别名 | 源定位 |
| --- | --- | --- |
| 时间 | `成交时间`、`时间`、`time` | 815，offset728–746 |
| 合约 | `合约`、`代码`、`symbol` | 816，offset748–766 |
| 数量 | `手数`、`成交量`、`volume` | 817，offset768–786 |
| 价格 | `成交价`、`价格`、`price` | 818，offset788–806 |

嵌套`_pick`809–814依次遍历别名与CSV表头，以`别名 in 表头`作包含匹配，遇到第一个匹配即将其值strip后返回；没有统一表头大小写、重复列歧义或同字段多列冲突检查。不能把该实现描述为严格一一列映射；例如泛化的`时间`可以先命中其他含“时间”的列。

CSV以`utf-8-sig`、`errors=ignore`读取（806，offset624–670），解码错误会被忽略，不是可验证的GBK/GB18030兼容方案。行中缺时间、合约或价格就跳过（819–820）；数量先取`vol or 1`再`int(float(...))`，价格为`float`，时间只保存`tm[-8:]`，合约仅upper（822–824，offset862–1018）。因此缺量会被猜为1，小数数量被截为整数，异常行静默跳过（825–826）；没有逐行错误报告或精确十进制约束。

本函数未读取账户标识、环境、交易日/完整成交日期、买卖方向、开平、成交ID、委托ID或手续费列。不能据此宣称其已验证这些范围，也不能据外部文件名或用户传入路径补造它们。

## 日志侧事实与近时匹配

日志侧仅匹配`[成交] ... (合约) 开仓 已成交 N手 ... 真实均价 ...（理论开仓价 ...，滑点 ...点）`这一类开仓文本。源regex与字段提取见785–801，offset14–582；时间从日志中另取`[HH:MM:SS]`。它不是完整订单/成交台账，没有真实成交ID或分笔绑定；其他平仓、人工或外部记录不能由这段regex自动取得。

| 步骤 | 已证实行为 | 源定位 |
| --- | --- | --- |
| 时间换算 | `_secs`把以冒号拆分的3段转int，返回`h*3600+m*60+s`；失败返回None，无日期/时区或时分秒范围验证 | 嵌套`_secs`831–836，offset4–190 |
| 逐日志记录查外部行 | 只接受未在used集合的外部行，且upper后的合约字符串与日志合约upper相等 | 838–843，offset1074–1242 |
| 时间窗口 | 两侧秒数均可解析，绝对时间差`<=180`，选最小差；相同差只保留先遇到行 | 844–849，offset1246–1384 |
| 数量和价格 | 两侧数量、成交价不参与匹配资格或选择 | 同一匹配块841–849；数量和价格仅在输出使用 |
| 去重 | 已选外部行的索引放used集合；并非成交身份、重复源行或跨文件去重 | 837、842、854，offset1050–1070、1158–1166、1540–1572 |
| 未匹配 | 对每条日志侧记录输出空白外部时间/价；循环结束后不另遍历和输出外部多余成交 | 850–853及其后写表流程 |
| 价差 | `round(外部成交价−本程序日志均价,2)` | 856，offset1592–1656 |

仅保留时分秒会跨不同日期错误地“接近”；带毫秒或其他尾缀的CSV时间取最后8字符后可能无法再解析。匹配没有账户/环境/交易日/方向/开平/成交ID/数量/价格的完整约束，不能把最近180秒命中称为自有成交归属证明。价差也没有方向化，不是资金盈亏或已确认执行滑点。

函数直接`wb.save(out)`（886，offset3020–3052），没有显式独占创建、已存在文件拒绝或防表格公式注入的分支。异常时返回读取CSV/写Excel失败消息；局部日志和CSV行异常则被静默跳过。

## 与费用归集及新产品边界

该对照函数没有手续费读取、费用分摊、写账本、账户资金更新或向交易接口发送请求的指令。DSV源的SDK成交手续费归集另见[资金静态证据](money-dsv-evidence.md#手续费来源去重与估算)，不能把它等同外部CSV费用导入。新产品若增加费用归集，是在独立明确合同下追加费用证据，不是静态证明发行包已有该能力。

原全功能计划V05/X09要求外部成交导入、双侧缺失/重复/账号日期不符可见、导出不能伪造确定净收益，同时不改原成交事实。独立实现可兼容上述中英文列名及可发现的离线入口，但需要明确账户/环境/交易日、精确价量、成交身份和多对一/歧义边界；不按源180秒近时猜配自动改账，不把外部成交导入为策略自有成交，不补下单或补平仓，不因重复或错账号文件重复登记费用。

本页仅为静态参考证据。开发实现、离线测试、GUI预览、文件导入预览及后续用户选择的费用归集结果应分别记录，不能由本页继承通过。
