# B01–B20 业务确认：全部以DSV为准

确认记录：`OT-DSV-CONFIRM-20261109-1`。规则集：`OT-RULESET-DSV-20261109-r2`。日期：2026-11-09。

**20项均已确认采用DSV基准。** 用户原话：“全部按dsv为准做确认”。本轮确认覆盖DSV保存的数值、开关和DSV实际业务行为标准；上一版由开发者自行新增或修改的推荐不随之获批。

实现语义尚未取证的内容转为开发侧技术核实项，不再要求用户重新确认“是否采用DSV”。不得把未知字段含义、PDF冲突或上一版建议填成DSV已验证行为。

本次只登记确认，未修改DSV配置、产品源码、运行账本或活动计划，未启动产品或连接柜台。现有内核持久化、订单归属和保护工程合同单独保留；业务对齐DSV需在后续实现中逐项验证。
