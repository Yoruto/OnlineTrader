# 人工交易、外部持仓接管和断线跨日恢复

2026-11-11，`0.1.0.dev23` 源码。验证使用离线柜台形状的输入、独立临时账本和本机工作台。现有账户及线上订单无操作。

## 人工范围与工作台

- 使用 `dsv scope --manual-workbench`（快期）或 `simnow scope --manual-workbench` 生成范围。范围绑定账户、原账本、合约、日期、日历、配置、时窗、手数、尝试次数和风险预算。快期读取无密码的账户档案，SimNow 读取无密码凭据引用。两个 `prepare` 入口均可离线审查。
- 快期可从账户工作台启动所选范围。命令行使用账户档案时，默认连接该档案的本机控制管道。SimNow 使用 `simnow run --pipe` 启动后，由 `workbench --pipe` 附着。人工范围以禁开状态启动，在已附着工作台选择“启用人工开仓”。
- 开多、开空由工作台提交合约、手数和限价。原内核绑定本期配置和保护，复核当前账户、风控、盘口、时效与数量后，经过原提交确认发送。限价保持操作者指定的价格。已成交部分受原保护，选定持仓的人工减仓与保护共用退出目标。
- 账户撤单以整批活动委托的快照指纹确认。包含外部活动单时，需要全部合约在人工授权范围内。原命令先提交，收到柜台终态并核对逐笔成交后才报告完成；未知撤单保留原请求。自有保护单被撤后，原目标仍由执行内核管理。

## 外部仓与恢复

- “柜台持仓差异”显示方向、柜台量、自有量和差额。已选合约没有活动自有周期及活动委托，且各方向今昨数量及开仓参考价有效时，可以确认接管该合约全部外部仓。双向仓一次确认，分方向建立两个保护周期。确认绑定账户、源 epoch、柜台日、全部持仓桶以及委托与成交集合的指纹。
- 接管事务登记原生仓位分配、保护计划及接管证据。账本保留真实成交和接管数量的独立口径，报表将未证明的历史成本和相应盈亏留作未知。上期所和能源中心按已证明的今昨仓桶选择平仓偏移。
- 多日范围按当前柜台日和来源 epoch 重新核对原委托、逐笔成交、持仓及今昨桶。旧日活动余单等待原生撤单终态后，按新日原退出目标分配子单。缺失未决单及未知发送继续占用原数量。断线和重启恢复原退出，人工开仓需要重新授权。
- “请求完整核对”持久保存原生资金、持仓、委托及成交查询。该操作保存查询证据，既有归属与发送屏障继续生效。

同合约自有仓和外部仓混合分配、外部加减仓与反手后的归属调整、缺失未决订单的远端历史回补，以及真实柜台成交、撤单和断线跨日验收仍待完成。

## 离线验证

12 组相关测试共 203 项通过，覆盖原工作台和控制回执、人工双向限价和减仓、外部仓快照变化拒绝、接管后重启、双向今昨仓退出、账户撤单终态及重复请求、同日重连、跨日旧单及未知发送。快期和 SimNow 的 `scope --manual-workbench` 与 `prepare` 均使用临时输入验证，期间禁止账户连接并确认未创建执行账本。源码和测试通过编译检查。
