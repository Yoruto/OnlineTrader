## 当前边界

- 每台 Windows 主机至多运行一个 Runtime；不同主机可以同时登录并操作同一期货账号。
- 期货柜台是持仓、委托、成交、资金和账户收益的权威来源。
- 每次启动创建当前进程拥有的临时执行账本；进程结束后丢弃，不在进程或设备之间交接。旧执行账本仅作为只读历史文件。
- 本机长期保存用户配置覆盖，以及可从柜台重建的历史与收益缓存；缓存不产生策略归属或恢复责任。
- 本文提出的 300 秒自动恢复规则未获当前设计授权。任何交易行为变化须有 DSV 依据或单独确认的范围。
- 历史数据覆盖不完整或不可用时必须如实显示，不能据此创建本机策略所有权。

旧草案的原始内容保留在合并历史中供追溯；后续设计和实现应遵循上列权威文档。
