## 现场首个差异

10:55:09 棕榈油 `DCE.p2701` 的日高为 9073、日低为 8949、现价为 9003。开仓偏移 32，止损偏移 16，止盈偏移 73，保护激活比例 0.8。

1. 振幅 `9073 − 8949 = 124` 超过上限 `2 × 32 − 16 = 48`，该轮不开仓。
2. 多头触发价是 `8949 + 32 = 8981`，激活价是 `8981 + 73 × 0.8 = 9039.4`。现价 9003 已触发开仓方向，日高 9073 已到过激活位，因而同时命中禁止追价。空头条件也成立，原版在两向都命中时先记多头。
3. 冻结版 `StrategyThread._run` 先记录振幅提示，检查该分钟是否已用，再执行激活位判断。日高和日低的激活边界均含等值。拒绝后写入 `last_signal_bar`，同一分钟后来转为空头也不会重新评估。原版文字跳过日志按合约和柜台日限频 600 秒，分钟状态每次实际命中都会更新。 [原版规则定位](../../strategy-dsv-evidence.md)

替代链的 `ordinary_entry` 在振幅超限时直接返回 `GEOMETRY_BLOCK`，跳过第二个判定和分钟更新。因此两边都没有报单，原版已有禁止追价记录和已用分钟，旧候选还保留了这次分钟机会。修复保留同轮的振幅阻断与定向禁止追价，写入触发价、激活价和已用分钟。未命中激活位的宽幅行情仍按几何规则阻断。工作台可悬停原因栏查看完整价格。 [策略修复](../../../src/online_trader/dsv_core/transition.py) · [独立设计的回归](../../../tests/test_dsv_round_replay.py)

已有几何和激活位组合测试覆盖旧 `strategy/entry.py`，替代链从 `dsv_core/transition.py` 进入。原有一组冻结循环样本关闭 `no_chase_after_act`，比较器检查目标、到期、名义净亏、日停和平仓同步，未校验这条拒绝及 `last_signal_bar`。现场两次初查也把零报撤成和相同的几何拒绝作为主要对照，遗漏 `[跳过]`。本次独立 Agent 先按原版现场和冻结回放列出预期，再复现两向优先级、同一分钟方向变化和换分钟。新回归在 `9590987` 失败，在修复源码通过。现场对照重扫记录纳入了 `[跳过]` 的合约、方向、触发价和激活价。 [原循环样本](../../../qa/dsv_parity/original_loop_samples.py) · [原比较字段](../../../qa/dsv_parity/compare_original_loop.py)
