## 5. 已确认的 B01–B20 规则逐条追踪

| 规则 | 取证结果及差异边界 |
| --- | --- |
| B01 规则身份与启动 | 本轮两边关自动／定时启动，属于此前用户授权下的共同配置。DSV 有按交易时段与错过时点补启的真实分支。OnlineTrader 定时字段可保存，当前实执行另走明确授权、时窗和范围 |
| B02 跑过激活位 | DSV 有实际规则取证，OnlineTrader 有离线实现。未取得同机会两边的真实输出 |
| B03 滞回 0 值 | 确认时撤回未取证的零值解释。后来静态取证发现 DSV 在计算时将保存的 0 回退为该品种止损距离，OnlineTrader 当前执行使用同样回退。本轮品种保存值为 0，非零路径和源异常下的行为待验 |
| B04 几何过滤 | 同公式、同等号边界。DSV 当前几何不合格不写日停。OnlineTrader 界面分类不等效 |
| B05 风险与手数 | 保证金、风险缩量和边界有 DSV 证据。最终保证金回退的价格、风险度取值、未知事实与预占有差异。OnlineTrader 在动态品种份额计算中还纳入工作台主动停用状态。前文 R01–R03 列出实际和潜在影响 |
| B06 收盘报价与撤改 | 两边有报价升级和撤改。DSV 依赖目标仓位任务和 SDK，OnlineTrader 使用原意图、子单和撤终态后续报。只有 DSV 本夜盘出现带仓收盘实成交 |
| B07 交易日与时段 | OnlineTrader 用显式日历与柜台日，DSV 有启发式日期逻辑。到期边界 DSV 把日期截到当地午夜取日差，OnlineTrader 使用完整到期时间戳。非午夜数据在临界点可能相差一天 |
| B08 延续开 | DSV 有夜盘参考、独立盘段判断和每日一次。当前 OnlineTrader 以首分钟普通入场分支附加标签，缺同等路径。本轮等待不豁免，影响待复现 |
| B09 同 K 线一次 | DSV 规则有信号消耗时点。OnlineTrader 持久化机会身份，旧版在回放提前消耗已构成实际差异，修复后待自然复测 |
| B10 双价与追单 | 有利方向豁免、双价阈值和等号已参考 DSV。OnlineTrader 对缺价、过期行情和发送前原事实更严格 |
| B11 价格与品种 | 在线路径使用原生最小跳动、合法价格和账户桶，禁止用拟定取整规则当 DSV 已证行为。真实临界盘口、涨跌停、交易所和量限制未逐项同测 |
| B12 名义统计与停开 | 方向化名义点数、净亏与连续停机参考原规则。记录时点、外部／人工归属、币种分离和跨日月停持久性不同 |
| B13 报单上限 | 同每品种上限，DSV 读策略计数，OnlineTrader 结合柜台订单与未覆盖的本地尝试，保留未决。所有撤改与拒单的计数未动态核对 |
| B14 保护与停止 | 80%／50% 和当日停开参考 DSV。F6 及停止撤挂单有明确差异。日盘同参数保存 `cancel_on_stop=true`，但 OnlineTrader 的 F6 明确传不撤开仓余单 |
| B15 断流与时效 | 原保存断流 180 秒，断流强平后日停开关关闭。DSV `>180`，OnlineTrader `>=180` 并用单调钟。当前执行器报价另设 5 秒，保存值 `max_quote_age_seconds=0` 未驱动此门槛。DSV 手工改仓同步使用至少 3 秒宽限，OnlineTrader 以原生事实核对和归属驱动。DSV 保存 0 的实际报价年龄语义待证 |
| B16 账户护栏 | 本轮未主动开启实盘 2 手／5,000 元和品种数护栏。OnlineTrader 仍有独立模拟授权预算，风险度由保证金／权益计算。DSV 对跑读取账户风险度。保证金变化提醒未交付 |
| B17 理论价与触发更新 | 理论触发和成交均价分列。DSV 可在人工同步时用账户均价重写保护。OnlineTrader 冻结原计划、按原生事实纳管和收紧退出。真实止损后的换线重开待验 |
| B18 半仓／保本／移动 | 阈值、阶段规则和数量参考 DSV。OnlineTrader 以真成交确认保本，DSV 有虚拟仓量更新。非默认开关的真实同仓样本缺 |
| B19 成交滑点退出 | 阈值和方向参考 DSV。原策略首次确认后判定，OnlineTrader 每笔真开仓成交更新累积均价并锁定目标。部分成交序列中可产生不同触发 |
| B20 首分钟与触发路径 | DSV 静态有变量来源异常线索，OnlineTrader 显式经过秒数、完整路径和回放限制，属于独立实现。有真实缺路径和迟到样本，正常与缺路径两条链未同验 |

## 6. 历史回补和等量换仓证据边界

- 快期固定 TqSdk 通道在已知历史原单号和成交号上只得到空占位，无完整原委托终态。夜盘同一柜台日确实查到 12 委托与 12 逐笔成交。前者不能代替后者，也不能据空占位释放 UNKNOWN。
- 当前 SimNow 通道查到两条螺纹钢昨多的合约方向、今昨手数及开仓均价，缺原成交号和开仓日期。总量相等无法证明哪些旧批次存续。
- 项目有本地原单留档和审核导入，完整证据可恢复原退出。等量换仓需要原批次身份、当前存续明细和完整换仓逐笔。混合接管、外部增减和反手已有离线场景，真实柜台证据仍缺。
- 快期专业版历史接口未在本机取到实际结果。SimNow 原生 CTP 独立持仓明细未实际接通。DSV 的真实历史原单回补、等量换仓批次辨认、带仓跨柜台日恢复均无此次实证。两套产品都不能从目前材料推定完整等效。
- 11 月 11 日午盘双方运行区间无可对照的开平仓，DSV 最后独立回查未取得。11 月 12 日日盘证据从 09:44 后开始，无完整开盘对照。已覆盖的最强交易样本是 11 月 11 日夜盘的单边快期成交。OnlineTrader 修复后的自然开、平、撤和带仓保护尚未验收。
